# AgentMeter-Coinbase-Hackathon
AgentMeter Coinbase Hackathon (2025)

## Features

### Wallet Connection
The chat application supports connecting to Base Sepolia testnet wallets:

- **MetaMask Integration**: Connect your MetaMask wallet to interact with the chat
- **Base Sepolia Network**: Automatically configured for Base Sepolia testnet
- **Balance Display**: View your wallet balance in real-time
- **Account Switching**: Seamlessly switch between wallet accounts
- **Auto-connect**: Automatically reconnects to previously connected wallets

#### How to Connect:
1. Click the "🔗 Connect Wallet" button in the chat header
2. Approve the connection in MetaMask
3. Ensure you're connected to Base Sepolia testnet
4. Your wallet address and balance will be displayed

#### Requirements:
- MetaMask browser extension installed
- Base Sepolia testnet configured in MetaMask
- Some test ETH for transactions (if needed)
